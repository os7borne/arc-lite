The start page applies changes immediately. Turning the start page off completely means removing the "new tab override" by disabling the extension.

Command bar

Shortcut click, then press the keys you want

Hold Shift while pressing Enter to use the other choice. Type > first to see only actions. On browser pages such as chrome://settings, where a page can't be drawn on, it opens as a small window; set a browser shortcut under Copy URL → Browser shortcuts for that case. The default shortcut is ⌘T, which replaces opening a new tab on web pages; on browser pages and anywhere the bar can't run, ⌘T still opens a normal new tab.

Action bar

The bar can't appear on browser pages such as chrome:// settings or the Web Store; Chrome doesn't allow extensions there.
